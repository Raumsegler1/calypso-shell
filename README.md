# calypso-shell

This is a quickshell for Hyprland that i made as a learning exercise and for personal use

# install steps (incomplete)

- clone Repo
- install dependencies
- rename user_config.example.json in ./config to user_config.json

# config options

- The city you live in, or want to see the weather for
- choose one of the available colorschemes or make your own
- availabe Colorschemes: gruvbox, nord, windowsCol tokyoNight
- design can be sharp, windows, circle or squircle
- the bar can float or not
- the margin between the screen and bar(while floating)
- position of the bar can be: left, right, bottom, top
- a custom icon to be displayed for your user

# Dependencies

- Quickshell
- Hyprland
- Networkmanager (nmcli)
- (rofi) optional
- hyprlock
- hyprshutdown
- a Nerdfont
