# calypso-shell

This is a quickshell for Hyprland that i made as a learning exercise and for personal use

## install steps (incomplete)

- clone Repo
- install dependencies
- create ~/.config/calypso-shell/ dir with the example user_config.json inside and edit it to your liking

## alternative

- add flake to your inputs
- add missing install dependencies
- create ~/.config/calypso-shell/ dir with the example user_config.json inside and edit it to your liking

## config options

- The city you live in, or want to see the weather for
- choose one of the available colorschemes or make your own
- availabe Colorschemes: gruvbox, nord, windowsCol tokyoNight
- design can be sharp, windows, circle or squircle or your own
- the bar can float or not
- the margin between the screen and bar(while floating)
- position of the bar can be: left, right, bottom, top
- a custom icon to be displayed for your user

## Dependencies

- Quickshell
- Hyprland
- Networkmanager (nmcli)
- (rofi) optional
- hyprlock
- hyprshutdown
- a Nerdfont

## Matugen support

- put the matugen generated .qml file into ~/.config/calypso-shell/colors/matugen
- then select matugen for colors in user_config.json
